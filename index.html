🕵️‍♂️ POC: Cross-Site Session Exfiltration

Esta página demonstra como um atacante pode exfiltrar dados de um usuário logado na Provafácil, mesmo que o script esteja rodando em um domínio de terceiros.

STATUS: AGUARDANDO EXECUÇÃO

Como Funciona

  1. O script faz uma requisição fetch para a API da Provafácil.
  2. Como credentials: 'include' está ativo, o navegador inclui o Cookie: sessionid da vítima.
  3. O servidor da Provafácil valida a sessão e retorna os dados do usuário logado.
  4. Como o CORS está mal configurado (reflete a origem), o navegador permite que o script leia a resposta.
  5. O script exfiltra os dados para o meu servidor.
Instruções:
  1. Abra o portal da Provafácil em outra aba (aluno.provafacilnaweb.com.br).
  2. Faça login com as credenciais de teste.
  3. Volte para esta página.
  4. Clique no botão abaixo.
