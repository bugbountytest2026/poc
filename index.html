🔬 POC: Cross-Origin Data Exfiltration via CORS

Esta página demonstra como um atacante pode exfiltrar dados sensíveis de um usuário autenticado na API da Provafácil, mesmo que o script esteja rodando em um domínio de terceiros.

STATUS: PRONTO PARA ATAQUE

Cenário: O atacante já obteve o Authorization Token da vítima (ex: via XSS, log de rede, ou interceptação). Agora, ele usa a misconfiguração de CORS para exfiltrar dados de qualquer origem.

Como funciona: O script envia uma request fetch para a API da Provafácil com o header Authorization e credentials: 'include'. Como o servidor reflete a origem (evil.com) e permite o header authorization (via preflight), o navegador permite a leitura da resposta.

1. Insira o Token da Vítima

Cole o Authorization Token da vítima (formato: Token [hex_string]). Você pode obtê-lo no DevTools da vítima (aba Network > Headers > Authorization).
